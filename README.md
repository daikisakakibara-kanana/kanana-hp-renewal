# 株式会社Kanana HPリニューアル

株式会社Kanana コーポレートサイトの刷新用リポジトリ。

## 方針
- ホームページ制作からシステム開発まで、ひとつの窓口で引き受ける会社として見せる
- 神奈川県小田原市に本社があることを打ち出す（ヒーロー、「Odawara, Kanagawa.」の帯、拠点セクション）
- 会社情報・事業名・システム開発の進め方と費用（補助金活用で実質25万円〜）は現行サイト kanana-tech.jp の内容
- デザインは estra.jp の余白・罫線・落ち着いた配色を参考にしつつ、構成と見せ場（ホームページ⇄業務システムの切り替え）はオリジナル

## 構成
- 静的サイト（HTML/CSS/最小限のJS）。ビルド不要。公開ディレクトリは `public/`
- `public/index.html` トップ（1ページ）
- `public/careers.html` 採用情報
- `public/assets/css/style.css` 共通CSS。色・文字サイズ・余白は冒頭の `:root` の値だけを使う
- `public/assets/js/main.js` メニューとヒーローの切り替え

## 公開（Cloudflare Pages）
Workers & Pages → Create → Pages → Connect to Git → このリポジトリ。Build command は空欄、Build output directory は `public`。
