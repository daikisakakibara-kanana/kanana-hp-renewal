# 株式会社Kanana HPリニューアル

株式会社Kanana コーポレートサイトの刷新用リポジトリ。

- デザイン: コンセプトは「設計図」。12カラムのグリッド・定規・寸法の注釈を地に薄く見せ、HP制作の会社であることを構造で伝える
  - estra.jp から取り入れたのは余白の取り方・罫線での区切り・落ち着いた配色・会社概要の組み方のみ（コード・文言・画像は使わない）
  - アクセントは設計図の青1色。書体は IBM Plex Sans JP / Archivo / IBM Plex Mono
- 会社情報・事業名: 現行サイト kanana-tech.jp の内容
- `public/index.html` の黄色マーカー（`.sample`）の文言はサンプル。確定したら `<span class="sample">` を外す

## 構成
- 静的サイト（HTML/CSS/最小限のJS）。ビルド不要
- 公開ディレクトリ: `public/`
- 色・文字サイズ・余白は `public/index.html` 冒頭の `:root` の値だけを使う
