# 料金体系（社内用メモ）

正本は Claude Docs の「Kanana 料金・プラン一覧」。サイト（`public/development.html` の「料金」「ご依頼にあたって」、`public/index.html` の事業欄）はこれに合わせている。
金額はすべて**税抜**。料金を変えるときは、料金・プラン一覧・サイト・このメモをそろえて直す。

## 考え方
- まず1件頼んでもらうことを優先し、小さく始めて後から足してもらう
- 目立つ場所には3つの数字だけを出す: ホームページ 5万円から／業務の自動化 10万円から／保守 月5,000円から
- サイトの制作は**買い切り**。公開後の保守は、必要な方だけ月額で契約する（任意）
- 制作費は一括払いが基本。分割払いも相談可
- 「〜」から金額が上がるのは、ページの追加と機能の追加がある場合だけ

## モニター価格（先着5社・2027年3月末まで）
ライト・スタンダード・システム開発を通常料金の半額で。条件は、完成後に実績として社名と画面を掲載させてもらうこと。先着5社か期限の早いほうで終了。

## ホームページの保守（任意）
- 月1万円: サーバー・ドメインの管理、文言・写真の差し替え（月2回まで）、実績・お知らせの追加
- 保守（ライト）月5,000円: 管理と月1回の差し替えだけ
- 契約しなくてもサイトは使い続けられる

## スポット対応 1時間 15,000円
自分で作ったサイトの部分的な作業（ドメイン・DNSの設定、フォームの設置、表示崩れの対応など）。最低1時間から。

## システム開発 30万円〜
内容によって大きく変わるため見積もり。相談・見積もりは無料。
- 保守運用（**必須**）月額2万円〜: サーバー・データベースの管理（サーバー代込み）、障害対応、セキュリティ更新、小さな修正（月1時間まで。超過はスポット単価）。機能追加は別途見積もり

## 今お使いのシステムの見直し
まず現状を聞き、費用と手間がいちばん少ない方法を提案する。作り直しが不要ならそう伝える。
| 方法 | 内容 | 向いているケース |
|---|---|---|
| 保守だけ引き継ぐ | 今のシステムはそのまま、保守をKananaに切り替える | 使い勝手は許容範囲だが、保守費が高い |
| 一部だけ直す | 使いにくい画面や手作業が残る部分だけ改修 | 不満が一部に集中している |
| 作り直す | 必要な機能に絞って作り直し、データを移す | 古くて限界、または中身を把握している人がいない |

- 相談と現状のヒアリングは無料
- ソースコードを読む調査はスポット対応の単価
- 保守を引き継ぐ場合の月額は現状確認のうえ見積もり

## ご依頼にあたって（サイトに掲載）
- AIを活用している（構成・文章・最終確認は担当者が責任を持つ）
- 預かった情報は制作以外の目的に使わない
- データは渡す。サーバーはお客様名義でも契約できる
- HPの保守は任意。システム開発は保守運用の契約が必要
