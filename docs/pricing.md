# 料金体系（社内用メモ）

サイト（`public/business.html` の「料金」「ご契約について」）に載せている内容の根拠と、決めたこと。
金額はすべて税別。**金額は提案段階の仮の数字で、確定したらこのメモとサイトの両方を直す。**

## 方針
- ホームページは **つくる内容は1つ（5ページまで）で、払い方を「月額」か「買い切り」から選ぶ**。プランを細かく分けない
  - 参考: kurumi.co.jp（制作費0円、月額 9,980円／19,980円、最低2年、月1回1時間の無料修正、超過 5,000円/時間、単発制作 96万円〜）
  - 月額と買い切りの合計が約30ヶ月で同じになるようにして、どちらを選ばれても損しない
  - 買い切りを 298,000円にしたのは、中小企業の「30万円未満の資産は一度に経費にできる」特例（少額減価償却資産の特例）を意識したため。適用条件は税理士に確認
- システム開発は **デモ画面 → 開発費 → 月額の保守・運用**。サーバーは Kanana が用意し、保守料に含める
  - デモは本番と同じ環境でつくり、そのまま育てて本番にする（移し替えをしない）
- 地元（小田原と近隣）は打ち合わせに伺う。それ以外はオンライン

## ホームページ
| | 月額でお支払い | 買い切り |
|---|---|---|
| 最初に払う額 | 0円 | 298,000円 |
| 毎月 | 15,000円 | 5,000円（管理を頼む場合。任意） |
| 内容 | 5ページまで | 5ページまで |
| ドメイン・サーバー・SSL | 管理込み | 月5,000円で管理、またはお客様で用意 |
| 修正 | 月1時間まで込み（超過 5,000円/時間） | 1時間 5,000円 |
| 最低契約 | 1年 | なし |

- 損益分岐: 298,000 + 5,000×n = 15,000×n → n ≒ 30ヶ月
- 6ページ以上、予約・会員などの機能があるサイトは個別見積もり（表には出さない）
- 買い切りで管理も不要な場合は、データを渡して終わり（サポートを残さない）

## システム開発
- デモ画面: 5万円（開発に進めば開発費から差し引き。HPの管理を依頼中の顧客は無料）
- 開発費: 50万円〜（分割払い可）
- 保守・運用: ベーシック 月1万円〜（サーバー・ドメイン・バックアップ・障害対応）／サポート 月3万円〜（＋月3時間までの修正、LINE・電話の問い合わせ）
- 時間を超えた作業: 8,000円/時間
- 最低契約: 1年

## 契約条件（サイトの「ご契約について」と同じ）
- 2年目以降は1ヶ月ごとの更新。解約は1ヶ月前までに連絡（買い切りに最低契約はない）
- 1年以内の解約は、残りの期間分の月額を支払い
- ドメインはお客様名義で取得。解約後もそのまま使える
- 解約時はサイトのデータ一式を渡す（データ移行費 3万円）
